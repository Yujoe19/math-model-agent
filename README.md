# 建模 Agent

一个本机运行的数学建模辅助原型。使用者填写自己的 DeepSeek API Key；模型根据任务决定是否调用论文检索或 Python 计算工具，然后解释结果。

> 该项目处于原型阶段，面向学习与研究。输出、文献、代码和比赛允许使用 AI 的要求，都需要人工核验。

## 功能

- 根据题目自主选择是否调用工具，最多调用 6 次；当前不提供连续对话或文件上传。
- 查询 Crossref 的论文元数据、作者、年份与 DOI。元数据不代表已经阅读全文，亦非通用网页搜索。
- 可选地在临时 Docker 容器运行 Python 标准库代码；显示模型传给工具的代码、真实输出和报错。
- API Key 每次由用户在页面填写，不写入项目配置文件。模型请求直接发送至 DeepSeek；检索词发送至 Crossref。

## 使用

需要 Python 3.10 或更高版本，以及一个有余额且支持工具调用的 DeepSeek API 账户。本程序仅使用 Python 标准库，无需安装 Python 依赖。

```bash
git clone https://github.com/Yujoe19/math-model-agent.git
cd math-model-agent
python server.py
```

浏览器访问 <http://127.0.0.1:8789/>，填写模型名称、Key 和题目。默认模型名称为 `deepseek-flash`；实际可用模型、工具调用能力和计费以服务商为准。工具是否启用由页面复选框控制；模型也可能选择不调用已启用的工具。

### 可选：启用 Python 计算

安装并启动支持 Linux 容器的 Docker Desktop 或 Docker Engine，预先下载 Python 镜像：

```bash
docker pull python:3.12-slim
```

然后在页面勾选“允许运行 Python”。沙盒容器不开网络、不挂载主机文件或 Docker socket、以非 root 用户运行，并限制 CPU、内存、进程数、输出长度和运行时间。运行前不会自动下载镜像。镜像需要通过你信任的镜像源取得。当前镜像只保证 Python 标准库；NumPy、SciPy、绘图及文件导入导出尚未配置。

Docker 隔离并不等于虚拟机级安全边界；不要用它运行不可信用户的任意代码来提供公共服务。超时会尝试停止并删除本次临时容器，若清理失败会提示手动检查 Docker。

## 使用与数据边界

- 服务仅监听 `127.0.0.1`，不是多人服务。不要转发端口或直接部署到公网。
- 密钥仅保留在浏览器和服务进程的运行时内存，不写入应用配置或请求日志；关闭页面或进程会清除相应内存。题目会传给 DeepSeek；勾选搜索后模型可能向 Crossref 发送检索词。
- Python 执行默认关闭；当用户勾选后，模型可以在调用上限内自主运行代码。实际代码、输出及异常显示在页面中，仍需审阅。
- 模型可能出错、生成无效代码、遗漏约束，或把搜索到但不相关的文章当成参考。公开发表及参赛前请逐项核对。
- 程序当前面向 DeepSeek 官方 API，模型名称可填写，但不代表所有名称或平台均兼容。

## 验证

```bash
python -m unittest discover -s tests -v
```

测试包含模拟模型的工具选择与调用上限、密钥不回显和跨站请求拦截，以及实际 Docker 容器的网络隔离和超时清理。运行完整测试需要 Docker 和上述 Python 镜像。模型调用的测试使用模拟数据，不会消耗 API 费用；首次使用真实 Key 时还需要实际验证模型连通性和能力。

## 开发状态

这是一个最小化原型，尚未实现项目保存、多轮对话、普通网页搜索、文件上传、图表导出、第三方模型供应商、自动调错重试或多用户隔离。欢迎先用公开练习题验证，再根据实际需求扩展。
